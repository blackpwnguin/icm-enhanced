## Instructions

1. Use @workspace-builder agent to handle the full process

   - Map steps to stages
   - Scaffold folders
   - Write CONTEXT.md contracts
   - Create config files
   - Generate questionnaire
3. After creation, suggest running `/project:setup-workspace [name]`
