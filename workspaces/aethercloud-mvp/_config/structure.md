# Structure Guide

## Format
- Opening: State the goal in 1 sentence. No preamble.
- Body: One section per major deliverable. Each section: what → why → how.
- Close: Exact next action.

## Length Targets
- Research outputs: 400-600 lines max
- Spec documents: 600-1000 lines
- Code files: as needed, but each file under 300 lines (split if bigger)
- All other stage outputs: under 200 lines per file

## Section Rules
- Headers describe what the section SAYS, not what it's ABOUT
- No bullet lists in prose — save lists for actual enumerations
- Code blocks only for actual code, commands, or file paths
- Tables for comparisons and matrices
