# Structure Guide

## Format

### Default Document Structure
- **Opening**: State the problem or question in 1-2 sentences. No preamble.
- **Body**: One section per key point. Each section: claim → evidence → implication.
- **Close**: What the reader should do next. One clear action.

### Length Targets
- Short form: 300-500 words
- Standard: 800-1200 words
- Long form: 1500-2500 words

### Section Rules
- Every section earns its place. If removing it doesn't hurt the piece, remove it.
- Headers describe what the section SAYS, not what it's ABOUT.
  - Good: "Context windows degrade after 30K tokens"
  - Bad: "About context windows"
- No section should exceed 300 words.

### Formatting
- Use headers for navigation, not decoration
- Bold for terms being defined, not for emphasis
- No bullet lists in final output unless the content is genuinely a list
- Code blocks only for actual code or file paths
